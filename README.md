# 💫 About Me:
Saya adalah siswa jurusan Pengembangan Perangkat Lunak dan GIM (PPLG) dengan minat besar pada pengembangan web, khususnya desain UI/UX. Saya berkomitmen untuk selalu antusias terhadap perkembangan teknologi terbaru dan konsisten mengasah keterampilan guna memberikan kontribusi inovatif di industri digital.
